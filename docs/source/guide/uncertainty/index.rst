.. _uq:

===========
Uncertainty
===========

This part of the guide builds the vocabulary that the rest of ``probly`` is
written in: where uncertainty comes from, how a model can represent it, how a
representation is turned into a number, and how to tell whether that number is
any good.

It is deliberately free of API calls. :ref:`core_pillars` operationalizes
everything here into the four stages of the library, and :ref:`methods`
catalogues the methods that implement them.

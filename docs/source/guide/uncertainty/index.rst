.. _uq:

===========
Uncertainty
===========

This part of the guide develops the vocabulary in which the rest of ``probly``
is written: where uncertainty comes from, how a model can represent it, how a
representation is reduced to a number, and how one can tell whether that number
is any good.

It is deliberately free of API calls. :ref:`core_pillars` turns each of these
questions into one of the four stages of the library, and :ref:`methods`
catalogues the methods that implement them.
